# PlotLab 绘图工作台 · 详细说明

PlotLab 是装在 DeepSeek Harness Web GUI 里的绘图工作台：**拖数据 → 说需求 → 自动剖析清洗 → 出图 → 页面调字体/字号/颜色 → 统计 → 带走图和代码**。
浏览器页面与 Agent 工具（`plotlab`）共用同一套 Python 实现，所以「点着用」和「让 Agent 干活」结果一致。

## 三步上手

1. **导入**：把 CSV / TSV / TXT / XLSX / JSON / GZ / ZIP 拖到页面任意位置（或点「导入数据」）。自动识别编码、分隔符、Excel sheet，自动判断是长表（一行一个观测）还是矩阵（首列特征、其余列样本），识别数值/分类/时间列并推荐分组列。
2. **说需求**：左侧「AI 需求」框写一句话，例如
   - `按 group 分组画箱线图比较 score 并标显著性，配色用色盲友好`
   - `画 score 和 age 的散点图，加回归线和相关系数，标题字号大一点`
   - `对表达矩阵做热图，按行标准化并聚类，配色用蓝红`
   - `做生存曲线，按 group 分组，加风险表`
   点「分析并出图」→ 解析图表/列/统计/风格关键词 → 自动清洗 → 出图 → 统计，并显示分析计划与理由。
3. **微调与带走**：中栏改图表参数与样式（实时重绘），右栏看统计/代码/历史，点「导出」拿 `bundle.zip`（图 + 代码 + 报告 + 数据 + 统计表）。

## 数据与角色

- **长表（tidy）**：一行一个观测，列是变量。适合柱/箱/散点/线/ROC/生存。
- **矩阵（matrix）**：首列是特征名（基因/代谢物/蛋白），其余列是样本；可挂样本表（`sample` + `group`）给矩阵图着色。适合热图/相关矩阵/PCA，也可融化成组间比较图。
- **列角色**：`x`（横轴/分类）、`y`（数值）、`group`（分组，驱动颜色与统计）、`color`（第二分组或连续着色）、`size`（气泡大小）、`facet`（分面）、`time` / `event`（生存）。每个图表声明自己需要哪些角色，左侧按需显示下拉框。

## 自动剖析与清洗

- 质量分 0–100 + 逐项检查：全空列、缺失率、重复行、常量列、ID 列、数字存成文本、异常值比例、分组均衡、样本量、高相关列、负值、数据规模；每项给中文说明与建议。
- 一键清洗（每步都有理由与前后行数，可按需重跑或恢复导入时数据）：删除全空列/常量列/重复行、数字文本转数值（自动去千分位/百分号，`<0.001` 取半值）、中位数填补（小缺失）、删除大缺失行、异常值缩尾（1.5×IQR）、log2/log10/ln/z-score/min-max/百分比变换、按列过滤、按组聚合。
- 清洗全部记录在 `protocol.json`，并原样重放进入导出的 Python 脚本。

## 22 种图表与样式

- **比较**：柱状图、柱散点图、箱线图、小提琴图、雨云图、点图、堆叠柱、饼/环图
- **关系**：散点图、气泡图、折线图、面积图、热图、相关矩阵、散点矩阵
- **分布**：直方图、密度图、QQ 图
- **统计**：ROC、KM 生存、森林图、PCA
- 有组间比较的图自动做检验并画显著性括号（Welch t / Wilcoxon / ANOVA / Kruskal，BH/Bonferroni/Holm 校正，星号/p 值/两者）。
- 样式全部实时生效：字体（含中文字体）、标题/轴标题/刻度/图例/注释字号、配色板（Okabe-Ito / NPG / Lancet / JAMA / Set1 / Set2 / Tableau / 马卡龙 / 灰度 / 连续色）、逐组自定义颜色、透明度、主题、画布尺寸、DPI（150/300/600）、网格、边框、刻度方向、标签旋转、对数轴、坐标范围、图例位置与标题、图标题/轴标题、误差线（SD/SE/CI95）、散点抖动、点大小/线宽/柱宽。

## 统计

描述统计、组间比较（自动选检验 + 效应量 + 事后两两比较 + 多重校正）、前提检查（Shapiro-Wilk、Levene）、相关（Pearson/Spearman/Kendall + p 值矩阵）、线性回归 / 二分类逻辑回归（系数、CI、R²、OR）、卡方/Fisher（Cramér's V）、正态性、ROC（AUC + bootstrap 95%CI + Youden 最佳阈值 + 敏感度/特异度/PPV/NPV）、生存（KM + log-rank + Cox HR）、PCA（解释方差、载荷）、多重检验校正。结果表可导出 CSV，并自动写进报告。

## 导出

| 类型 | 内容 |
|---|---|
| `figure` | PNG 300 dpi（可选 PDF/JPG 位图） |
| `code` | 完整可运行 Python（读取 → 清洗 → 作图 → 统计）+ ggplot2 片段 |
| `report` | Markdown 报告：数据概览、质量检查、清洗日志、图、统计表、代码、复现步骤 |
| `methods` | 英文 Methods 段落（可直接进论文） |
| `protocol` | 溯源 JSON：引擎/Python/包版本、参数、角色、样式、清洗记录、图的文件 |
| `cleaned` | 清洗后数据 CSV（UTF-8 BOM，Excel 可直接打开） |
| `stats` | 统计结果表 CSV（每张表一个文件） |
| `bundle` | 以上全部打成一个 zip |

## Agent 用法

对话里直接说「用绘图工作台把 xxx.csv 导入，按 group 画箱线图比较 score，配色用 NPG，然后导出打包」，Agent 会调用 `plotlab` 工具完成；页面同步显示。工具 action：
`status / open / demo / inspect / preview / profile / clean / reset_data / roles / charts / plot / stat / auto / code / export / records / audit / suggest / need / samples / formats / reset / engine_restart`。

## 限制

- 暂不提供 SVG 矢量导出（PDF/JPG 为位图转换）。
- 超大矩阵自动取方差 top 特征；散点超过 3000 点自动抽样，都会给出提示。
- 统计结果依赖数据是否满足前提（时间/事件列、二分类标签、足够样本量）；不满足时明确报错或警告，不编造结果。
- 图内文字默认英文；中文标题请在样式里选中文字体（本机已装 Arial Unicode MS / 苹方 / 宋体）。
